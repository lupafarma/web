# Lupafarma

Herramientas libres para farmacias españolas.

---

## Productos

### [Lupa](https://lupafarma.es) · [`web`](https://github.com/lupafarma/web)

Auditor de facturas farmacéuticas. Detecta sobrecargas, errores aritméticos y oportunidades de ahorro comparando contra el Nomenclátor de Facturación y el PVL Industrial de Referencia publicado en BOE.

**Procesamiento 100% local en el navegador.** Sin registro, sin cuenta, sin telemetría.

→ Probar en [lupafarma.es](https://lupafarma.es)
→ Ver el código en [`lupafarma/web`](https://github.com/lupafarma/web)

---

## Filosofía

- **Datos públicos.** Todo se construye sobre Nomenclátor de Facturación, BOE y Reales Decretos en vigor.
- **Privacidad verificable.** El usuario puede comprobar con F12 que no se envía nada a ningún servidor.
- **Software libre.** Licencia MIT, código auditable, sin caja negra.
- **Castellano por defecto.** Pensado para el contexto regulatorio español.

---

## Fuentes

Todos los productos usan exclusivamente datos públicos:

- [Nomenclátor de Facturación](https://www.sanidad.gob.es/profesionales/nomenclator.do) — Ministerio de Sanidad
- [BOE Orden SND/1118/2025](https://www.boe.es/diario_boe/txt.php?id=BOE-A-2025-20356) — Sistema de precios de referencia
- [Real Decreto 823/2008](https://www.boe.es/buscar/act.php?id=BOE-A-2008-9291) — Márgenes regulados
- [Real Decreto 177/2014](https://www.boe.es/buscar/act.php?id=BOE-A-2014-3189) — Sistema de precios de referencia
